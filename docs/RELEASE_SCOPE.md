# Free preview release scope

Candidate 0.4.0rc6 is prepared for owner-approved publication. The downloadable
wheel is the free local execution path; Python 3.11+ and a writable private
workspace are required. Navigation needs no model credential, GPU or dataset
download. The optional competition recipe is a separate, unexecuted cloud path.

rc6 adds missing robomimic/robosuite license notices for the retained Can XML and
metadata, updates installation/repository metadata and version labels. Core task,
authorization, runner and verifier behavior is unchanged from rc5. Earlier
archives are immutable and are not replaced by rc6.

Historical acceptance: WP33 native installation/upgrade used rc1 (minimum and
working Python), and isolated Kali/Linux container execution used rc2. WP34
static-documentation/browser/quickstart used rc3. WP35 installed Agent Skill and
one subscribed-client navigation integration used rc4. WP36 external adapter
installation and common worker execution used rc5. These are tested scopes,
not a newly repeated rc6 compatibility matrix. Broad client/OS compatibility,
hosted multi-user operation, external SSO and physical robot safety are unproven.

M7 remains ACCEPTED_LIMITED_SCOPE. The twofold action-reduction target was not
demonstrated, and both independent agent studies retained failed verdicts.
No full independent-agent certification or external adoption is claimed. M8
remains ACCEPTED_PREPARED_SCOPE; publication, indexing and competition submission
are separate actions.

The included published street report is a saved recording. Running the quickstart
creates a new result through the common service and independent grid checker.
Can recordings, read-only state viewing, simulator action replay and physical
replay are different levels of evidence. The original HDF5 and private 209-episode
workspace are not distributed. Obtain optional datasets from their attributed
sources under their own terms; navigation works with the included original maps.

The proposed public source is a clean release snapshot, not the private project
history or full agent traces. The owner retains those historical records.
