Scope of this comparison

This adapter executes the pinned external PythonRobotics Dynamic Window Approach planner. The project file selects numerical parameters, point obstacles, a start pose and a goal. It cannot execute uploaded Python, shell commands or arbitrary adapters.

Clearance and reaching the goal are separate outcomes. A no-regression search means no regression was found in the recorded budget. It does not establish safety, production readiness or a performance advantage over other tools.
