What this check establishes

The returned route reaches the original goal, stays on passable cells, makes only legal neighbouring moves and does not cut blocked corners. Its length is recomputed from the route and compared with the dataset's independently supplied optimum.

A match means this solver passed these cases. It does not demonstrate a discovered defect or a WorldFuzz search advantage. The nine rows were selected by their 25%, 50% and 75% positions in each file before execution. Negative outcomes are retained.

Repeat the fixed suite from the WorldFuzz checkout:

python scripts/run-published-benchmarks.py --out artifacts/new-published-run

This starts up to 12 local solver calls and saves a new report with original inputs. This page itself only plays the recorded routes.
