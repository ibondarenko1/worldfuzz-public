WorldFuzz turns a supported robotics task or an existing recording into a bounded run with its inputs, versions, permissions, resource usage and checked artifacts kept together. Use the same service from a browser, Python, a terminal or an MCP agent.

What you need

  • Python 3.11 or newer on a tested Windows or Linux placement; an operator-supplied wheel or an authorized source checkout.
  • A writable private workspace and permission to use its source data. Published Moving AI inputs are bundled; Can HDF5 and personal recordings are not.
  • Finite time, CPU, memory and artifact limits. Optional simulation and dataset readers need their pinned dependencies.

What you receive

A durable run ID, separate execution and task outcomes, a verification report, source/profile versions, artifact hashes and a usage ledger. You can compare compatible results, download original files and build versioned datasets while preserving rights and linked groups.

Evidence you can interpret

A saved report is a recording. Reading it is not new execution. A new run passes compatibility, owner permission, source rights and resource checks. An integrity check validates stored bytes; a supported metric checker recomputes a defined result. Neither proves physical robot behavior.
