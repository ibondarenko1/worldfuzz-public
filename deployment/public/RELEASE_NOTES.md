# WorldFuzz 0.4.0rc6 — free local preview (publication proposed)

Run published grid navigation through one platform service from a browser,
Python SDK, CLI or MCP. Keep the exact resource, source/profile versions, budgets,
task outcome, independent verification and downloadable artifacts together.

The bundle contains source, wheel/sdist, static English documentation, an
installable Agent Skill, a separately installable numeric adapter example and
third-party notices. Install the wheel into Python 3.11+ and use a new writable
workspace. The navigation quickstart needs no model key, GPU, HDF5 or cloud bill.
Data/replay extras have separate prerequisites and source rights.

rc6 adds full robomimic/robosuite notices for retained Can XML/metadata and updates
public-preview setup and proposed repository metadata. The previous rc1–rc5
archives remain unchanged. Runner, API business logic and verifier behavior are
unchanged from rc5; prior installation/container/agent evidence is not relabeled
as an rc6 matrix. The new optional Nebius recipe is prepared separately and has
only offline/mocked-provider local diagnostics so far.

M7 remains ACCEPTED_LIMITED_SCOPE and M8 ACCEPTED_PREPARED_SCOPE. The 2x workflow
benefit was not demonstrated; both independent agent studies retained failed
verdicts. Software checks do not certify physical robots. Broad compatibility,
public multi-user hosting, external adoption and a fresh Nebius job remain
unverified. Saved reports are recordings, not new executions.

Read README and docs/RELEASE_SCOPE.md. Verify every download against the reviewed
SHA256SUMS/manifest.json. No package/catalog presence or website availability is
claimed until the owner actually publishes and checks it. License: MIT for
